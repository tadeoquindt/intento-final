# Stop Terror

Sitio web estático de cinco páginas sobre habitaciones de Escape Room de terror.

## Estructura
- `index.html`: página principal.
- `pages/`: La Muñeca, La Cura, Escape y Sobre mí.
- `scss/`: estilos fuente organizados en partials.
- `styles/main.css`: CSS compilado desde SCSS.
- `assets/`: imágenes del proyecto.

## Ejecutar localmente
1. Instalar Node.js.
2. Abrir una terminal en esta carpeta.
3. Ejecutar `npm install`.
4. Ejecutar `npm run build-css` para compilar SCSS.
5. Ejecutar `npm run watch-css` mientras editás SCSS.
6. Abrir `index.html` con Live Server.
